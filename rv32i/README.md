# MiniRubik on RV32I

Optimal solver for the 2×2×2 cube in hand-written RV32I assembly, for
Assignment 1 of Computer Architecture (Fall 2026). The write-up is the
HackMD note: https://hackmd.io/@kevin20031015/arch2026-homework1

## Files

| File | What it is |
| :-- | :-- |
| `solver.s` | The solver: input check, ranking, IDA* search, replay check |
| `tables.s` | Move and distance tables, generated by `gen_tables.c` |
| `led.s` | LED Matrix renderer (GUI build only) |
| `solver_led.s` | `solver.s` plus the calls to the renderer |
| `final.c` | The same algorithm in C, compiled by GCC for Section 4.3 |
| `rv_io.h`, `tables.h`, `gcc2ripes.py` | Build `final.c` for the host and for Ripes |
| `gen_tables.c` | Prints `tables.s` |
| `verify.c`, `verify_out.txt` | Gates H1–H3 and their output |
| `run_tests.ps1` | Six test cases on Ripes |
| `stats.c`, `stage3_counts.c` | BFS level counts and Stage 3 operation counts |
| `measure_log.txt` | Commands and output for the numbers in the note |
| `measure/` | Ripes memory and speed measurements, and the run over all 2,644 distance-11 states |

## Build and run

The scripts assume Ripes at `D:\claude\ripe\tools\Ripes\Ripes.exe`;
change the path at the top of each script.

**CLI build** (the one measured with `--iret`):

```
cmd /c copy /b solver.s+tables.s full.s
Ripes.exe --mode cli --src full.s -t asm --proc RV32_ISS --iret
```

**GUI build** (LED Matrix):

```
cmd /c copy /b solver_led.s+led.s+tables.s gui.s
```

Open `gui.s` in the Ripes GUI and add an LED Matrix in the I/O tab
(Width 35, Height 25, the default).

**Tests:**

```
powershell -ExecutionPolicy Bypass -File run_tests.ps1
powershell -ExecutionPolicy Bypass -File run_tests.ps1 -proc RV32_5S
```

**Tables:** `gen_tables > tables.s`

AI use is described in the note's AI Usage Disclosure.
